API Governance Rules

API Commons publishes 1,568 Spectral-compatible rules across three areas: 588 OpenAPI rules covering every aspect of REST API design from paths and operations to schemas and security; 130 APIs.json rules validating the structure and completeness of API index files; and 628 provider spectral rulesets encoding the specific design conventions used by individual API providers. Rules come in error, warn, and info severity levels and can be applied individually or assembled into rulesets for CI/CD pipelines.
