API Governance Rules

API Commons publishes 776 Spectral-compatible rules — unique, provider-agnostic patterns, each solving a single governance problem. Coverage spans 573 OpenAPI rules from paths and operations to schemas and security; 128 APIs.json rules validating index file structure; 47 JSON Schema rules; 26 OWASP security rules from the OWASP API Security Top 10; and 2 AsyncAPI rules. Rules come in error, warn, and info severity levels and can be applied individually or assembled into rulesets for CI/CD pipelines.
