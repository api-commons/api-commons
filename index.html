What is API Commons?

API Commons is where you find the open source building blocks of API operations. API Commons began as a machine-readable artifact to define the licensing of your API, but has grown to support getting started, authentication, plans, SDKs, road map, change log, and support. API Commons works in concert with APIs.json to help translate the human-readable properties of your API operations into machine-readable ones that can be used to help standardize and automate your API ecosystem.

If we are going to take things to the next level with APIs and AI, there are aspects of our API operations we need to stop competing upon and begin using common building blocks. The API Commons is much more than just enabling machine-readable API discovery with APIs.json, it is about making sure all the common aspects of API operations, but also applications and integrations using those APIs is as machine-readable and scalable as possible.
